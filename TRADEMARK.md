# Menew name and logo

The Menew for Linux source code is free software under the [GNU General Public License v3](LICENSE), the same as the [Mac app](https://github.com/Quost/menew). The **name “Menew”, the Menew icon and logo, and the website menew.pururucos.com.br** are not covered by that license: they identify the official app made by Matheus Quost.

## You can

- Say that your project is based on Menew, or that it works with Menew (“a fork of Menew”, “built on Menew”).
- Use the name and icon to talk about Menew: articles, reviews, videos, tutorials, lists of apps.
- Build Menew from source for yourself, with the name and icon, as long as you don’t distribute it.
- Package the **unmodified** official source for a Linux distribution under the name Menew, as long as it is clearly the same app (distribution patches that only fix building or integration are fine).

## Please don’t

- Distribute a modified version, a fork or a repackaged build with changed behavior under the name Menew or with the Menew icon. Give it another name and icon so nobody confuses it with the official app.
- Use the name or icon in a way that suggests the official project endorses or makes your product.
- Register domains, app names, accounts or trademarks that include “Menew” for a different product.

## Official downloads

The official Linux builds are published only on [GitHub Releases](https://github.com/Quost/menew-linux/releases) and linked from [menew.pururucos.com.br](https://menew.pururucos.com.br).
